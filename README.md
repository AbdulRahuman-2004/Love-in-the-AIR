# Love-in-the-AIR
A romantic interactive Love Garden with hand-gesture drawing, floating hearts and flowers, personalized names, music, and memorable moments — built with HTML, CSS, and JavaScript.

# 💗 Love in the Air — Our Love Garden

Welcome to **Love in the Air**, a romantic and interactive website created to celebrate love through creativity, gestures, flowers, and hearts. 🌹💕

This project transforms simple hand movements into a beautiful digital love garden.

## ✨ Features

- 💗 **Interactive Love Garden** — create romantic drawings on the canvas.
- 🖐️ **Hand Gesture Drawing** — draw using supported hand gestures through your camera.
- 🌸 **Romantic Effects** — enjoy floating hearts, flowers, sparkles, and other love-themed animations.
- 💌 **Personalized Names** — display special names in the drawing area.
- ↶ **Undo Drawing** — remove the last drawing stroke.
- 🗑️ **Clear Canvas** — clear the drawing area and start again.
- 🎵 **Background Music** — enjoy music while creating your love art.
- 🎥 **Save Memories** — save drawings and record your creations, if supported by your browser and implementation.
- 📱 **Responsive Design** — designed to work on desktop and compatible mobile browsers.

## 🛠️ Technologies Used

- HTML5
- CSS3
- JavaScript
- MediaPipe Hands for hand tracking, if enabled in the project

The `images/` and `music/` folders are optional and should be included only if your website uses them.

## 🚀 How to Run Locally

1. Download or clone this repository.
2. Open the project folder in Visual Studio Code.
3. Make sure all required images, audio, and other assets are present.
4. Open `index.html` using the Live Server extension.
5. Allow camera access when prompted if you want to use hand gestures.

## 🌐 Live Website

After publishing with GitHub Pages, add your website URL here:

**Live Demo:** `https://YOUR-USERNAME.github.io/love-in-the-air/`

Replace `YOUR-USERNAME` with your GitHub username and update the repository path if you choose a different name.

## 📷 Camera Permissions

Camera-based drawing requires browser permission and a secure context such as HTTPS or localhost. Results may vary depending on device, lighting, browser, and camera quality.

## 🔒 Privacy

This is a front-end web project. Do not upload personal photographs, private videos, or private audio files to a public repository unless you are comfortable making them accessible to others.
